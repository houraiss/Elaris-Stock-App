Elaris: React Native (Expo SDK 57) inventory + sales app for a jewelry
shop in Morocco — gold/silver pieces priced by weight, EN/FR/AR UI.
`expo-sqlite` + Drizzle ORM is the local source of truth, synced to
Supabase. UI follows the design system in `src/theme/` and
`src/components/` — reuse it rather than hand-rolling new styles.

Read `AGENTS.md` (environment/version gotchas) and `PROGRESS.md`
(current build status + the next planned step) before starting work.

# Elaris — web preview

**Open it: https://houraiss.github.io/Elaris-Stock-App/**

Elaris is a stock and sales app for jewellery shops: gold and silver pieces
priced by weight at the day's market price, sales and receipts, customers,
repairs, buy-back and more, in English, French, Arabic, Tamazight and Hebrew.

This repository hosts a **preview** that runs in the browser on Android,
iPhone and computers. It is a demo: it has no cloud account, and everything
you enter stays in your own browser. Some features of the full app (cloud
sync, sign-in, cameras, notifications, AI reading) are not part of it.

On a phone, use "Add to Home Screen" to open it like an app.
